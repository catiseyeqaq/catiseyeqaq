## About

我是 `YuXuanLin`，人工智能方向硕士研究生，关注 `YOLO改进`、`大模型调参`、`边缘端部署` 和 `工程化落地`。  
目前主要围绕 `基坑隐患识别`、`无人机热成像检测`、`私有化智能系统` 进行研究与实现。

## Focus

- `Detection`: 面向复杂真实场景的小目标检测与结构改进
- `LLM`: 大模型微调、RAG、私有化部署与多模态级联
- `System`: 从算法到前后端再到部署交付的完整闭环
