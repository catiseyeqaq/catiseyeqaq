## About

我是 `YuXuanLin`，人工智能方向硕士研究生，关注 `多模态生成`、`YOLO改进`、`大模型私有化部署` 与 `商业化交付`。
当前主线：基于 **ComfyUI + MiniMax-H3** 的 AI 漫剧/影视内容生产系统（8×96GB 加速卡集群），以及检测类智能系统的行业落地（煤矿、无人机搜救、水务、宠物健康）。所有在研项目均按 **商用标准** 交付。

## Focus

- `Generation`: ComfyUI 工作流编排 + 视频大模型（T2V/I2V/R2V）+ 提示词 LLM 级联的漫剧生产流水线
- `Detection`: 面向复杂真实场景的小目标检测与结构改进（SPDConv / BiFPN / P2 / NWD）
- `LLM`: 大模型微调、RAG、私有化部署与多模态级联（Qwen 系列 / SGLang / DashScope）
- `System`: 从算法到前后端再到部署交付的完整闭环，全部按商用标准交付
